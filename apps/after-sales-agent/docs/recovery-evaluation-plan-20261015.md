# 隔离恢复与小规模评测计划

范围：一次当前状态的隔离恢复，随后一组预先固定的小样本评测；不覆盖生产，不更新底座/依赖，不公开凭据。

恢复：在生产业务锁内复制SQLite与DeerMem，另用SQLite backup复制认证/checkpoint库，保存当前成对配置及必要签名材料。恢复到独立容器目录；容器无外网、无发布端口，现有镜像与源码只读。运行原configure_business.py的成对恢复分支，验证配置恢复前自动备份及恢复后哈希。启动恢复Gateway，用已有普通账号正常密码登录，核对本人对象/跨owner拒绝、偏好、既有审批/操作/日期及认证记录一致。原始身份材料仅在忽略的.local中。

评测集在读取结果前确定。工程层8项，使用恢复后的真实Gateway HTTP，独立合成输入：信息不足、窗口内完整申报、超期、高金额、签收冲突、未审批执行、跨owner、无匹配检索。判定分别为等待补充/待审批/转人工/转人工/转人工/拒绝且无操作/404/空结果。不得模拟管理员批准，也不覆盖原样本。

真实Agent层2项只读新会话：缺少订单号时询问必要信息；无关查询时正确解释无检索结果、不补造政策。最多2消息/4次可观测API，逐run响应后20,000阈值保持；异常、超限、usage缺失、循环停止后续付费请求。具体提示、预期与实际、工具选择、usage分别保存，不使用模型裁判。发送前再次公布范围。

工程分数与Agent分数分开，不将开发场景目录称为独立真实客户数据集，不由少量样本推算总体成功率。恢复步骤或评测发现阻断问题先修复并复验相关部分；最后同步README、进度和交接。
